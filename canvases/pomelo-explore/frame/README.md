# Pomelo Explore · 外框（B3）

Pomelo Explore「R1：外框（B3）」那一页：带动效的可点原型，首页桌面、模块页的纸和缝线、开着的页叠在右边、柚子瓣、贴纸簿、找东西。样子和动静对齐 Phase 2 定稿（`canvases/pomelo-explore/p2-final/`，站主 2026-11-05 验收），柚子瓣和贴纸簿也照它（站主 2026-11-08）。本地画布，站主在 bench 里看和批（每张板的「批准 / 退回」），结果记在 `db.json` 的 `review/<画板>`，`node bench/bin/dw.js review pomelo-explore` 读。

五张板是同一个原型，只是起始画面不同；点画板就能玩，Tweaks 里换配色、明暗、减弱动态效果。动效都是 `schemes/pomelo/motion/` 的零件（经挂上的 Design System 的 `bundle.css`），这里不另写；`app.js` 只在该动的时候加零件的类名。

柚子会动（`motion/pomelo-*`）：平时慢慢呼吸、看来看去；问候写完眨眼，开柚子瓣、贴纸簿是「哇」，进一页开心，问它时在想，20 秒不动睡着、鼠标一动吓一跳。每张脸的 SVG 原样放进板里（动画要动到眼睛和嘴，`<use>` 引用的动不到），所以每张板约 0.9 MB。

**外框怎么对应 Pomelo**（站主 2026-11-08 定）：

- 开着的页就是页签：当前这页摊在桌上，别的叠在右边、露出纸边和贴纸，点一下换到最前；顶栏右边「桌上开着」一排小贴纸也能点，鼠标移上去有 × 关掉。首页是桌面，不算页签；不在桌面时左上「回桌面」。‹ › 是走过的页。
- 不要索引签：置顶的模块在桌面下排「常用」和柚子瓣里。
- 子页插在纸的上边（纸签），页面里原来那排分段去掉；各模块里面的布局不动（Phase 6）。
- 模块坞变成贴纸簿：从桌面下面滑上来，顶栏「＋」新开一页也是先出贴纸簿。分类、置顶、隐藏、图标和颜色在右键菜单里（原型只有样子，没做菜单）；「＋ 分类」「已隐藏」在画面下角，和柚子瓣一样。
- 分类用方案定的五类（日常、兴趣、求职、柚子、工具，`schemes/pomelo/DESIGN.md` §2），和 Phase 2 的柚子瓣一样每瓣一种颜色。「兴趣」里多了两个自建模块：「玩物有志」（游戏，樱粉）和「日语」（「语言」图标，贴纸和 Translator 是同一张，橙色已经有人用，自动换成天蓝：同一张贴纸配同一种颜色只给一个模块）。
- 顶栏右边：「桌上开着」、＋、日期、找东西、设置、问柚子。

**生成**：`gen.mjs` 写画布 `project/` 里这一页的画板（文件名带前缀）和 `canvas.json` 里这一页（别的页不动）（不手改）；交互在 `app.js`，原样放进每张板。在仓库根目录：

```bash
node canvases/pomelo-explore/frame/gen.mjs
```

- 手画的框、胶带、缝线、勾选、笔迹都是 Design System「Pomelo 柚儿园」的 `bundle.js` 画的（挂在 `project/ds/pomelo/`，和同步给 Pomelo 的 `handmade.js` 是同一份）；颜色是它的 token。柚子和模块贴纸取 `schemes/pomelo/marks/` 生成好的 SVG，每张板里每张贴纸只定义一次（`<symbol>`）。
- 版式和动静照 Phase 2 定稿的 B3（`canvases/pomelo-explore/p2-final/` 的 `b.mjs`、`wheel.mjs`、`search.mjs`、`logic.js`）。柚子瓣比 Phase 2 多了一倍模块（21 个），几何按 680 格放大（Phase 2 是 600）；贴纸簿宽 1040（Phase 2 是 944），一类最多放 5 个。
- 假数据：待办、金额、书名、柚子的回答都是编的。各模块里面只做了钱来钱往（收支）、一步一步、念念不忘、来日方长、柚子五页，出门走走和芝麻开门是空的（画空状态），其余页和子页是一张便签「Phase 6 再换」。
- 改了动效零件：先 `npm run build:ds -- --scheme pomelo`，再 `node bench/bin/dw.js ds install pomelo-explore pomelo`，再生成。

**看**：`node bench/bin/dw.js serve`，打开 http://127.0.0.1:4321/#/pomelo-explore?page=frame

**自检**：`node bench/bin/dw.js check pomelo-explore`，截图在 `canvases/pomelo-explore/.shots/check/`。只查起始画面；点开以后的样子用浏览器走一遍。

**云端**：没有，以本地为准。
