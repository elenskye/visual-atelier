# 联动和玩物有志（EX6、EX7）

Pomelo v1.0 Phase 5 的设计，站主 11-15 在现用账号的云端画布 [Pomelo · 联动和玩物有志](https://claude.ai/artifact/WiXRSdag98S76mVQB92eL8) 上批的；云端停在那一轮，只看。

| 页 | 画板 | 看什么 |
| --- | --- | --- |
| EX6：跨模块联动 | 15 张 `Links-*` | 文章里嵌一条念念不忘、光标进到小卡露出 `![[…]]`、打 `[[` 的提示（文章、念念不忘）、笔记卡片里的链接、写文章时右边那栏念念不忘（拖一条进正文）、选一段「记到念念不忘」、文章最后和书影面板里链到这里的 |
| EX7：玩物有志 | 5 张 `Games-*` | 表格和筛选、平台的下拉（管理平台）、面板和周目、三个贴纸方案 |

- **站主定的**：贴纸挑 B 掌机（已搬进 `schemes/pomelo/marks/art.mjs` 的 `MODULE_ICONS.games`，方案 `0.8.0`）；便签里「要你定」的三处照画的（笔记用日期时间认、平台不配颜色、周目和完成时间合在一起）。
- **批的时候改的**（在 Pomelo 里做，这两页留着批的样子）：「链接到这里的」「读后感」「观后感」「玩后感」统一叫「柚子链接」；选中一段字也能链到 Pomelo 里的东西，写成 `[[模块/名字|字]]`，颜色用方案新加的 `link-pomelo`（柚子链接色，和普通链接分开）。
- `lib.mjs` 外框、图标、贴纸和小控件（三个贴纸方案的起稿留在这里，EX7 的贴纸板照旧并排）；`pages.mjs` 每张板的内容和样式；`gen.mjs` 写两页（`../page.mjs` 的 `writePage`）。假数据都是编的。

```bash
node canvases/pomelo-explore/links/gen.mjs
```
