#学习/编程

生命周期不是让值活得更久，而是告诉编译器几个引用之间谁比谁活得长。能编译、编译不过、待查、问柚子，四种颜色各标一处。

rust fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
// 返回值活不过 x 和 y 里短的那个
let s = "柚子".to_string();
