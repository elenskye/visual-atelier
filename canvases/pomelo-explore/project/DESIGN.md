# DESIGN.md（Pomelo 柚儿园）

已定的视觉基线和待确认点，任何视觉改动前必须完整阅读。基线站主 2026-11-05 批准（VL2 · Phase 3）。数值在 `tokens/`，这里写规则；过程和每轮的选择在 `history/`。

**一句话**：一张摊开的桌面，上面是手账。手画的墨线、错开一点的颜色、带白边的贴纸、胶带和纸；纸可以歪，字永远是正的、清楚的；处处有小动静，动起来都像纸和贴纸。

## 1. 方向

- **给谁用**：Pomelo（柚儿园），只在站主自己的 Mac 上用、不分发。设计可以大胆跳脱，只考虑站主自己的体验。
- **气质**：清爽、有活力、手作感，手作当主角。手作感来自手绘线条、纸张纹理、贴纸和胶带；活力放在图形和插画、文案和小彩蛋、动效。现代的手作，可以试 ins 日系。交互借鉴 Not Boring 系列的物理手感，不做声音。
- **反关键词**：后台表格感、通用线条图标感、装饰堆砌；古朴安静（那是站主的个人网站）；Bear、Things 3 的样子。
- **外框**：B3 桌面拼贴。首页是桌面，便签能拖能甩；模块页是摊在桌上的纸，左边缝线；左上角的柚子点开柚子瓣，首页的贴纸簿也留；开着的别的页叠在右边。
- **角色**：柚子是唯一的角色，就是 AI，也是顶栏、菜单栏（实心表示模型就绪、空心表示没运行）、AI 按钮、App 图标。「小拾」只留给 v1.0 之后的 Old Timer。
- **边界**：不取用 Vermilion 的 token、规则与资产。内容图标是唯一的例外，只给「呦呦漫游」的内容图标选择器用，Pomelo 自己的界面不用。

## 2. 色彩

所有颜色都在 `tokens/color.json` 一个文件，明暗和 5 套配色都过 APCA（`tokens/contrast.json`，正文 Lc ≥ 75，次要文字和交互色 Lc ≥ 60），`npm run qa` 逐套逐明暗查。

**角色**（每套配色都有，明暗各一份）：

| 角色 | 管什么 |
| --- | --- |
| 桌面 `desk` · 桌面暗 `desk-deep` | 桌子的底色、拖动时的投影区 |
| 纸 `paper` · 卡面 `card` · 方格线 `grid` · 细线 `line` | 模块页的纸、白卡、纸上的线 |
| 墨 `ink` · 淡墨 `ink-soft` | 正文、次要文字 |
| 笔 `pen` | 手画的线条、边框、缝线点、悄悄话 |
| 主色 `primary` · `on-primary` | 按钮 |
| 选中 `selected` · 荧光笔 `marker` | 选中底色（跟主色走）、强调的一抹 |
| 链接 `link` · 危险 `danger` · 涨 `up` | 链接、删除和截止、钱涨了 |
| 顶栏 `top` · 当前页签 `tab` | 色面家族的顶栏是墨色 |
| 贴纸墨线 `art-ink` · 白边 `art-white` · 投影 `art-shadow` | 贴纸和图形 |

**五套配色**（浅色的关键值）：

| 配色 | 家族 | 桌面 | 笔 / 主色 | 选中 | 荧光笔 |
| --- | --- | --- | --- | --- | --- |
| 蓝笔 · 方格纸 `blue`（默认） | 钢笔 | `#ECEDE5` | `#2340A8` / `#2B4BC0` | `#E1E7FF` | `#FFD23F` |
| 紫笔 · 樱粉荧光 `purple` | 钢笔 | `#F1EAF0` | `#4A32A6` / `#5B3FC4` | `#FFE1EC` | `#FFBDDF` |
| 黑笔 · 牛皮纸 `kraft` | 钢笔 | `#E1CCA9` | `#1F1D1A` / `#1F1D1A` | `#FFF0A0` | `#FFD23F` |
| 柚黄桌面 `yellow` | 色面 | `#FFD23F` | `#20241F` / `#20241F` | `#FFEE9E` | `#FFD23F` |
| 薄荷桌面 `mint` | 色面 | `#81E5B9` | `#1E2A24` / `#1E2A24` | `#D3F5E5` | `#FFD23F` |

- **钢笔家族**：笔色管线条和按钮，荧光笔管选中。**色面家族**：桌面整片上色，顶栏墨色；深色时反过来（桌面墨色、按钮用桌面色）。
- **分类色 5 种，各套共用**：薄荷 `#3DBE8B`、天蓝 `#4AA8E8`、樱粉 `#F78FB3`、橙 `#FF9A3C`、葡萄紫 `#9B87F5`。只当圆点、图表和贴纸，不写字。每种派生三档：浅底（和卡面混）、淡底（和纸混）、贴纸填色（和白混 70%）。哪个模块归哪一类 Phase 8 定。
- **收进同一个色板**：Pomelo 现在的 19 种模块色、8 种选项色、4 组状态色、6 种图表色都映射到这 5 种分类色和墨色上（`tokens/targets.json` 的 `pomelo`），字一律是墨色，靠圆点和底色分。
- **柚子的固定色**：柚黄 `#FFD23F`、叶子 `#44B56E`、腮红 `#FFA3B8`。柚黄只当底色和点睛，不当文字。
- **危险色和主色明显分开**：浅色 `#C8322A`（色面家族 `#E0362B`），深色 `#FFA291`。
- **便签和贴纸不跟明暗走**：便签纸 `sticky`、贴纸填色在深色下也是浅色的，上面的字用 `on-sticky`。
- **印出来的东西**（年度小报、票根、信纸）用固定的纸色 `print-*`，不跟配色走，深色模式下也是浅色的纸。

## 3. 字体与排版

- **字体**（`type/fonts.json`）：手札体（Hannotate SC）管界面，钱和统计数字也用它；柚子的长回答和来信用苹方。两个都只作 Mac 上的运行时字体，不转曲线、不进产物。手札体要按 `@font-face` 分别声明两个字重，不然粗体发糊。手札体的数字等宽，金额右对齐就齐。
- **字号**（`tokens/scale.json`）：正文 14–15，次要 12–13，卡片标题 17，页标题 22–26，统计数字 20–30 粗，问候 46 粗；行高 1.45–1.75。
- **网格**：以 4 像素为单位。桌面画板 1280 × 800，模块页的纸 1140 × 716。
- **圆角**：纸 10、卡片 14、按钮 10、标签 8、贴纸和统计数字是圆的。
- **字要清楚**（站主定的，正式版不能出现糊字）：纸、胶带、贴纸可以歪，字永远是正的，停下时不缩放、不挂 `will-change`，落在整像素上；拖动、翻页这种动起来的时候可以例外。文本框聚焦时不出现额外的方框，手画的边描粗一点。字离它所在的框左右至少 6，上下不出框，框按内容算大小。样稿每次发布前跑版面检查（`tooling/qa/canvas-lint.mjs`）。

## 4. 图形语言

画法是 S3 线描贴纸：手画墨线，颜色错开一点，剪成带白边的贴纸。参数全在 `tokens/handmade.json`，生成器是 `tooling/handmade/`，抖动算进路径，同一个种子永远得到同一条线；不用运行时的 SVG 滤镜画抖动。

**形状词汇**：

| 形状 | 用在哪 | 要点 |
| --- | --- | --- |
| 纸 | 模块页、简报、便签 | 圆角 10，手画边，纸纹；模块页和简报的左边一列缝线点 |
| 卡片 | 首页的块、弹出的原记录 | 白卡，圆角 14，手画边，一到两条胶带，两层柔和投影 |
| 贴纸 | 模块图标、柚子、统计数字、打卡 | 墨线描边，填色错开一点，外面一圈白边（模切），轻投影，歪着贴 |
| 胶带 | 卡片、便签、照片、标签底 | 两种：薄荷斜条纹、柚黄斜条纹；两端锯齿；第一条贴上边居中附近，第二条斜贴一个角 |
| 缝线点 | 纸的左边 | 短横线一列，间隔 18–20，半透明的笔色 |
| 小票 | 资产、找东西、年度小票 | 白纸，锯齿底边，虚线分段，数字右对齐 |
| 票根、信封、信纸 | 年度小报（Atlas） | 票根两侧缺口；信封是牛皮纸，柚子贴纸封口；信纸浅色带横线 |
| 纸星星 | 年度小报、打卡、撒小贴纸 | 鼓鼓的五角星，填分类色；最重要的几颗是描墨线的柚黄金星 |
| 笔迹 | 强调、完成、选中 | 荧光笔划过（字下面）、墨线划掉、手写下划线、十字绣的 × |
| 柚子 | 唯一的角色 | 梨形，带叶子；8 个表情（平常、在想、眨眼、困了、开心、出错、惊讶、哇）；墨色只用实心小点，不和错开的填色叠在一起 |

**不用**：果切色块、橡皮章颗粒、通用的细线图标、扁平几何色块、表格网格线（表格用整行底色和留白分行）、装饰堆砌（一张卡片最多两条胶带、一张贴纸）。

**线条**：

- **图形**（模块图标、贴纸、插图，64 格）：墨线 3.3、抖动 0.75；填色比墨线错开 (1.4, 1.8)；白边 4.2；投影向下。墨线在钢笔家族用笔色，在色面家族用墨色。
- **界面小图标**（24 格）：一笔单线 2、抖动 0.32，跟着文字颜色，没有填色和白边。选中时底下抹一笔荧光笔，不加方框。
- **框**（卡片、按钮、输入框）：手画圆角框，线宽 1.6–1.9；输入框聚焦时描粗到 2.8。
- **分割**：手画横线 1.6；小票用 2 像素虚线；表格不画竖线。

**歪**：只有纸、胶带、贴纸歪。卡片和便签 −2.2°～+2°，贴纸 ±8°，第一条胶带 −4° 上下 3°，第二条斜贴约 ±30°。

**大小**：模块贴纸 24 / 26 / 30（行内）、52–60（桌面下排）；菜单栏 16；App 图标源图 1024。

## 5. 动效

**性格：像纸和贴纸在桌上动**。拖着走有惯性、碰到桌边弹回；贴纸撕起来、松手落回去轻轻一弹；纸能翻页；小票打出来、撕下来；什么东西出现都先画出来再弹一下。数值在 `tokens/motion.json`，取自站主验收的小样。

| 性格 | 用在哪 | 数值 |
| --- | --- | --- |
| 果冻弹 | 完成、勾选、按下、贴纸啪地贴上 | 弹性曲线 `cubic-bezier(.3,1.6,.5,1)`；按下 0.08 秒缩到 0.9，松开 0.38 秒弹回；贴上 0.45–0.55 秒 |
| 画完再弹 | 等待（柚子在想）、出现（空状态、新卡片、每一幕） | 线条先画出来 0.5–1 秒，再一样样弹一下，间隔 0.07–0.3 秒 |
| 纸的物理 | 拖动、甩、撕、翻、打印 | 惯性每帧乘 0.92（转盘 0.95）；翻页 0.8 秒 `cubic-bezier(.35,.1,.2,1)`；贴纸落回先越落越快，压一下再弹平 |

**两档**：

- **`calm`**：控件的小动静。「都不要安静」：每个控件碰一下都有回应，但正在读的长文本身不动。可以弹，不能循环，单次不超过 600 毫秒。
- **`expressive`**：招牌时刻和柚子的表情，单次不超过 3 秒，要登记在 `tokens/motion.json` 的 `registeredSurfaces`。只有柚子的表情和等待时的动画能循环。

**柚子**：平常慢慢呼吸（2.6 秒一次）、眨眼、看来看去；在想时眼睛跟着转、光点浮起；开心跳两下；出错摇头；20 秒不动睡着，鼠标一动吓一跳。

**节拍**：Atlas 自动翻页一拍 0.8 秒，翻一页是一拍；每一幕停几拍写在节拍表里。音乐和声音由 Pomelo v0.9 接，VL2 不做声音。

**减弱动态效果**：停在最后的样子，循环停下，自动翻默认关；字照样清楚。

**六个招牌时刻**：

1. **打开 App 的问候**：便签一张张落到桌上，「下午好呀」一笔写出来、荧光笔从底下划过，柚子眨一下眼。
2. **呼出柚子瓣**：点左上角的柚子，它转着长成一圈柚子瓣；拖着能转、松手接着转，打字就找，打「柚子」它转一圈。
3. **柚子在想和回答**：柚子画完再弹进来，眼睛跟着转、光点往上浮；回答一个字一个字写出来。
4. **年度总结（Atlas）**：新年第一周桌上多了一个柚子贴纸封口的信封；拆开，一本小报跟着节拍自己翻，碰一下就停。年度小报的形式站主认了（2026-11-05），各幕是初稿，Phase 11 做全。
5. **完成待办或打卡**：勾选框果冻弹一下，墨线把那一行划掉；全做完撒一把小贴纸。
6. **空状态**：插图一笔笔画出来，再一样样弹一下，配一句俏皮话，不写使用提示。

**文案**：全中文，俏皮，像柚子在跟你说话。空白页一句话（「书架空空，去摸会儿鱼吧」），不写使用提示。AI 叫「柚子」。
