# App

App 图标。底板占画面 7/8，深海渐变，每个尺寸一格都是整像素：

- `peck-j2.svg` — 主图标 J2，32 格的鸟；256、512、1024 用（一格 7、14、28 像素），带一圈光和底板阴影。
- `peck-j2-128.svg`、`peck-j2-64.svg`、`peck-j2-32.svg` — 照 J2 缩的 28 格鸟；128、64、32 用（一格 4、2、1 像素），64 以上带光。
- `peck-j2-16.svg` — 14 格的鸟，16 用。
- `peck-a3.png` — 现在的图标润色过的（A3），设置里能换成它；只出 Dock 用的 128 以上。

颜色都写死在图里（青 #00E5FF、冠羽 #A8F6FF），不跟明暗变。
