L布局LAYOUT

  • L1

    窗口外边距上 22、左右 30、下 28；顶栏 44 高，往下隔 16 是三栏。

  • L2

    三栏：左 288 放项目和任务，中间自适应放新任务和对话，右 336 放右栏四个模块（R1）；栏间 16。

  • L3

    顶栏只放：品牌 PECK、项目名、模式（CLI / API）、额度与花费、设置。

  • L4

    每栏是几块模块竖着叠，间距 16；一栏最多一块撑满，其余按内容高。

  • L5

    中栏最下面固定一个「输入位」：平时是输入框；要你回答、批准或填东西时，卡片占住它，处理完输入框回来。

  • L6

    整页的东西（设置、额度与花费）占中栏和右栏合成的宽栏，左栏不动；右上 CLOSE 回到原来的任务。

R右栏SIDE

  • R1

    右栏顶上一条页签：CHANGES / ONE SHOT / FILES / TERM，一次开一个；页签是分段（K3）。

  • R2

    切走以后，页签上说那边有新东西：CHANGES 写改了几个文件，ONE SHOT 答完一颗点，TERM 命令在跑转圈、跑完一颗绿点或红点；终端锁着时 TERM 上一把锁。从不自己切走你在看的页签。

    CHG
  • R3

    每个模块头右边一个 EXPAND，展开到宽栏（L6），再点收回右栏。展开时任务停下来等你，宽栏顶上一条琥珀提示，点 BACK 收回去。

  • R4

    ONE SHOT 问一句答一句：能读整个项目，不改文件、不跑命令（CLI 用 PLAN 档跑，API 只给读文件的工具）；读了哪些文件写在回答上面。任务进度、终端输出它看不到，用 + 带上；带上 FILES 里的文件是「指着它问」。

    CHG
  • R5

    ONE SHOT 谁来答：Muse、Grok 和配了 Key 的 API 模型都能选（K10），默认跟顶栏的模式，换了就记住。API 答完写这一问花了多少（算进花费上限），CLI 写「订阅额度」。回答只给 COPY 和 TO TASK。

    CHG
  • R6

    FILES 只看不改：照忽略规则藏起 node_modules 这些，写一句藏了几个；这个任务改过的文件标法和 CHANGES 一样（NEW、DEL、+ −）。

  • R7

    FILES 预览：带行号；改过的行左边一条绿，删掉的文件预览删之前的样子并写明撤销能放回来；图片、二进制、太大的不预览，写一句为什么。

  • R8

    TERM 是你自己的终端，在项目根目录：不经过权限三档、不进模型上下文；Agent 跑的命令在中栏步骤里看，不进这里。

  • R9

    TERM 每条命令跑完写 EXIT 码和用时，不是 0 就红；命令在跑时输入行暗着，旁边只有 STOP（I6）。

    CHG
  • R10

    模块之间只靠「带上」和「跳过去」连：FILES 的 ONE SHOT、DIFF，TERM 失败那条的 ONE SHOT，都是切页签，不开新窗口。

  • R11

    模型在跑任务时终端锁着（站主 11-10 定）：从发出到做完，等你批、等你答、撤销的时候都算。输入行换成一把锁和一句为什么；输出照样能看、能带去 ONE SHOT；发任务前就在跑的命令接着跑，STOP 一直能点。

    NEW
  • R12

    做完终端就解锁。之后你改的文件不算进这个任务：撤销只动任务改过的那几个，确认里写清你后来改的不动。

    NEW

K控件CONTROLS

  • K1

    按钮高 34，切两级台阶（每级 2）；同一时刻只有一个青色主按钮：有几个输入框时（任务、ONE SHOT、TERM），只有正在写的那个的 SEND 或 RUN 亮。

  • K2

    危险的按钮红边红字；真要删的那一下（确认里）才用红底。

  • K3

    分段、选项片、页签：选中块也切台阶；小东西（标签、开关的钮、单选点）切一格。

  • K4

    输入框青边，前面一个 ›；光标是一格闪的方块。

  • K5

    进度用方块（28 格或 20 格），不用细线；头一格闪，等你时头一格变琥珀。

  • K6

    图标是 8×8 像素格，画成 16（小处 12），不混别的图标集。

  • K7

    设置行：左边名字和一句说明，右边控件；行与行之间点线。

  • K8

    页内导航竖排：英文大写一个词，下面一行中文小字；选中块切台阶。

  • K9

    模块头和预览头里的小按钮：26 高、没有底，一两个英文词；只有图标的（EXPAND）26 见方，带名字给读屏。

  • K10

    菜单：从点它的选项片上方弹出，按组列（组名英文大写小字），当前那项青底；用不了的不列，组底下一行 + 当场补（S4、I7）；再点一下选项片收起。

    NEW

T字TYPE

  • T1

    名字（任务名、步骤名、问题、选项、项目名）用缝合像素 12；大标题 18，首页 24。

  • T2

    说明用 Plex Sans + 苹方 12.5，小字 12。

  • T3

    代码、路径、命令、文件名用 Departure Mono 11。

  • T4

    数字、标签、按钮、模块头用 Doto 900 英文大写；计时大字 54。

  • T5

    字号不小于 12；唯一的例外是代码用的 Departure Mono 11（站主 11-10 定）。像素字只用整数倍字号。

C颜色COLOR

  • C1

    青只给能点的主操作和正在发生的事：主按钮、选中、进度、在跑、光标、链接。

  • C2

    琥珀 = 等你；绿 = 完成、新增；红 = 删除、高危、出错、撤销；紫、橙、蓝 = Muse、Grok、API 的身份色点。

  • C3

    深色：青 #00E5FF，带强光；浅色：深青 #007A94 配白字，进度块 #0099B8，不发光。

  • C4

    底是 LED 点阵孔（8 像素一颗，很淡）；面板不加渐变、不加阴影。

  • C5

    代码不按语法上色：颜色只留给意思（绿新增、红删除、青在发生、琥珀等你），注释和行号用暗字。

S空、加载、出错STATES

  • S1

    空：一句话说现在是什么情况，再给下一步（一个按钮）；不画插图。

  • S2

    加载：写清在等什么；短的用 3×3 点阵转圈，有进度的用方块，超过 10 秒写已经等了多久。

  • S3

    出错：红边模块；第一句说发生了什么，第二句说怎么办（按钮）；原始报错放代码字里，默认收起。

  • S4

    用不了的东西：任务里不直接列出，收进 MORE，选了当场补（I7）；设置里照样列出来，灰掉，写一句为什么（「没配 Key」「没检测到」）。

M模块和卡片MODULES

  • M1

    模块两层：外层是边线色，里层是面板色，四角切两级台阶，每级 3。

  • M2

    模块头写 [ LABEL ]：Doto 英文大写 14；右边一句说明，或一个 Doto 数字。

  • M3

    状态看边：在跑青边，等你琥珀边，出错红边，其他灰边。同一时刻只有一块模块描彩边。

  • M4

    模块里的分隔用 1 像素点线，不用实线，也不再套一层卡。

  • M5

    卡片（问你、高危、确认、填 Key）= 模块 + 彩边 + 头上一个 26 方块图标；出现时边一格格点亮。

I交互FLOW

  • I1

    发任务 = 一句话 + 谁来干 + 权限（PLAN / EDIT / AUTO，默认 EDIT）；⌘↵ 发出。

  • I2

    高危的事开始前一张卡一次批：EDIT 时是删文件、联网装依赖、改项目外的文件；AUTO 时只剩删文件和改项目外的（推送也算项目外）。项目外的默认不勾。

  • I3

    跑的时候有问题才停下来问；单选、多选、判断题，数字键选，⏎ 提交，esc 先放着。

  • I4

    做完默认留着；撤销整个任务前在原地确认一次（不弹窗），写清几个文件、回到几点、Git 不动。

  • I5

    一时不能做、或做了会怎样的事，用底部提示条说一句（墨底，2.8 秒）。

  • I6

    同一个项目一次跑一个任务；在跑时输入框暗着，旁边只有 STOP。

  • I7

    要填 Key 时卡片占住输入位；Key 打码，存进钥匙串；「已保存」和「认证通过」分开显示。

  • I8

    权限三档：PLAN 只读，读代码、写计划，不改文件、不跑命令；EDIT（默认）改文件、跑命令不问；AUTO 装依赖、联网也不问。

  • I9

    谁来干：CLI 模式四种（Muse、Grok、Muse → Grok、Grok → Muse），API 模式两种（单模型干活、规划 + 实施）。单次请求不在这里，挪进右栏的 ONE SHOT（站主 11-10 定）。

A动效MOTION

  • A1

    点阵管出现、消失、进度；位移按格子跳，不用平滑缓动。

  • A2

    弹扣只给正在跑的那一步。

  • A3

    扫描同一时刻只有一道：发出、等你、完成、撤销各扫一次；在跑那一步每 2.8 秒扫一次。

  • A4

    一次性动作 1 秒内做完；卡片的边 0.8 秒点亮，内容 0.4 秒露出。

  • A5

    减弱动态效果时只留最后的样子。

W文案WORDS

  • W1

    标签、按钮、模块头：英文大写，一两个词（SEND、UNDO TASK、[ CHANGES ]）。

  • W2

    句子用中文，说清后果：「回到 14:02 开始前的样子，你的 Git 不动」。

  • W3

    用词照 design.md 的对照表：任务、步骤、谁来干、改动、任务前快照、撤销整个任务、额度与花费、设置。

  • W4

    状态词只用：在跑、等你回答、完成、失败、已停止、已撤销。

  • W5

    时间写 14:02、3 分钟前、11-10 14:02；金额写 $3.20 / $20，不知道的写「未知」。
