QUESTIONS要你定

  • 1发任务时终端还有命令在跑？

    比如 pnpm dev。我画的是接着跑、STOP 一直能点；它要是改了项目里的文件，也算进这次改动。另一种是发任务前先问你要不要停它。

  • 2ONE SHOT 默认谁来答？

    我画的是跟顶栏的模式走：CLI 模式默认 Muse，API 模式默认「谁来干」里选的模型；换了就记住。另一种是默认最便宜的 API 模型（快，但要配 Key）。

  • 3PLAN 档的任务也锁终端？

    PLAN 只读，不锁也不会混进改动。我画的是也锁：一条规则好记，也免得你改掉它正在读的东西。
