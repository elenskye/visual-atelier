## 3. 分析和评估：用三家 Agent 测了一遍 Atelier

站主的判断是三家的结果都不如人意。我（本仓库现在的 Claude 会话，也是 Claude 那一版的作者）同意，下面是看了三家最后一轮的板和全部提交以后的结论。

### 3.1 三家最后一轮各自的长短

- **Claude（EX1 页）**：每个方向的图形词汇最统一，线、茎、卡、卵石从容器一路贯穿到图标、状态和动效，节奏也最克制；三屏之间的连动做得完整（脚注翻回文献库、设置改变对话）。短处：四套用的是同一个三栏骨架，变的是表面、不是结构；配色全是纸色底；动效没目视过。
- **Codex（EX2 页）**：结构最干净，交互链最像真产品（切方案保留状态、Word 修订到确认应用、设置关掉自动选技能以后要点名）；C 观测站的「文献星图」是三家里最有新意的文献库。短处：A 和 C 的对话是同一套骨架换了颜色，三套的差别主要在配色、字体和导航的位置；大片留白、组件偏通用（下拉框、普通按钮）；最后一轮改成普通 HTML 加外挂脚本，不是画布的模板写法，在 Claude Design 的编辑器里改不了。
- **Argon（EX3 页）**：四套的空间骨架差别最大，一屏里装下了整条研究链（角色、技能轨迹、四类句子、WonderLab 节点图、Word Diff 确认）。短处：信息过密，装饰词汇堆得多（`[SKILL://01]`、24 格刻度、四芒星轨），离「淡雅、简约」最远；A、C、D 仍是米色纸底；一张板引 13 个字体家族。

### 3.2 三家共同的问题

1. **收敛到模型的默认审美**：第一轮三家几乎一样——旧纸或暖米纸的底、苔绿或髓心绿、一个暖色点缀、衬线标题、植物发芽的动效。之后几轮绿色退了，纸色底一直在。
2. **骨架趋同**：最后一轮基本都是「左栏 + 对话 + 右边证据或成果」，差别落在颜色、字体和装饰上。
3. **工程量压过了设计量**：三条分支加起来约 4.4 万行插入（Claude 约 1.0 万、Codex 约 0.67 万、Argon 约 2.66 万），大头是生成器、字体子集、对比度门槛和交互外壳；同样的基础设施三家各写了一遍。
4. **规矩执行不一**：Codex 最后一轮不用画布模板，Argon 的生成器绕过 `canvases/_lib/root.mjs` 直接引依赖。规矩写在文档里，工具不拦。
5. **看不到动**：`dw check` 的截图是减弱动效下的终态，三家的交付说明里都写着「动效没目视」。动效是简报说的亮点，却是三家都没法自己检查的部分。

### 3.3 原因：提示词和 Atelier 各占一半，引擎不是主因

画板格式和运行时两边是同一套，所以引擎本身不是主因。问题出在给 Agent 的说明这一层，以及探索阶段的工程门槛。

**简报和提示词这一半**

- 简报的形容词（淡雅、简约、灵动、少科技感，参考 Maggie Appleton）和模型的默认审美几乎重合。没有反例、没有具体参照、没有「不要像什么」，三家自然落到同一个地方。
- 第一轮就要整套方案（token、Design System、动效零件、质检全过），方向还没定，精力先花在工程上了。Peck Explore 能成，是因为第一步就是三个方向的整屏，一步一验收。

**Atelier 这一半**

- **只给流程，不给设计功夫**：Claude Design 自带一份 craft.md，要求先拿 2–4 个真正不同的低保真方向给人看，挑一个大胆的、问「哪一点让人记住」，还点名提醒「奶油底、衬线标题、陶土色是你的惯性」。Atelier 的 `design-loop` 只讲怎么写、怎么查、怎么发，一句审美都没有；`CLAUDE.md`、`ROADMAP.md` 和各份 `DESIGN.md` 大多是规矩和「不做」清单。
- **探索阶段就上了定稿的门槛**：生成器拼 HTML、逐字节一致、字体子集、APCA 门槛，这些该在收敛成方案时做。
- **Agent 看不到自己画的东西在动**：只有减弱动效下的截图，没有按时间线截帧。
- **本地运行时旧了**：11-21 云端 Design 类型带的 `dc-runtime.js` 是 197,599 字节，`bench/vendor/claude-design/` 还停在 11-06 的 188,749 字节。
- **缺共用的探索零件**：一张板多屏、共用状态的外壳，字体子集、配色检查，三家各写了一遍。

### 3.4 改 Atelier（站主 11-22 定的第二步，11-22 七条都做了，结果在 `CHANGELOG.md`）

1. `skills/` 加一份中文的设计功夫说明（对应 craft.md：先 2–4 个低保真方向、一个大胆的选择、点名默认惯性、动效集中在一个时刻），`design-loop` 开头指过去。
2. 探索阶段直接写画板；收敛成方案时再上生成器、逐字节一致、字体子集和 APCA 门槛。
3. 简报模板加上参照、反例和「要避开的默认」，第一轮只要低保真的几个方向。
4. `dw` 加按时间线截帧（不减弱动效），让 Agent 能看到动效。
5. 换掉 bench 的运行时副本，让 `dw` 能查出运行时过期。
6. 把一张板多屏的外壳、字体子集、配色检查做成共用零件（`tooling/` 或 `canvases/_lib/`）。
7. `CLAUDE.md` 等规则文档再精简一遍。
