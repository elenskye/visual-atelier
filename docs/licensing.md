# 许可

只有可再分发许可的字体才能转曲线、打包进产物。新增字体先在这里登记。

| 字体 / 素材 | 用途 | 许可 | 可转曲线 / 打包 |
| --- | --- | --- | --- |
| Source Serif 4 | 网站标题与长文（拉丁） | OFL 1.1 | 可 |
| Work Sans | 网站界面与正文（拉丁） | OFL 1.1 | 可 |
| Noto Serif SC / Noto Sans SC | 网站中文；Pith 读的字和界面的字的中文（`schemes/pith/type/fonts.json`，画布和 Design System 从 Google Fonts 取，不打包） | OFL 1.1 | 可 |
| Newsreader、Lato | Pith 读的字（Newsreader）和界面的字（Lato）（`schemes/pith/type/fonts.json`，画布和 Design System 从 Google Fonts 取；App 打包时整个带上） | OFL 1.1 | 可 |
| Lucide 图标 | 网站界面的通用图标（Vermilion；Pomelo 2026-11-09 起换成自己画的） | ISC | 可 |
| 手札体（Hannotate SC） | Pomelo 原生界面（Pomelo 方案；不属于 Vermilion） | macOS 系统字体，授权归 Apple。Pomelo 只在站主自己的 Mac 上用、不分发，按「本机调用、不打包、不转曲线」使用，不再往下查（2026-11-03，站主）；要给别人用时先查 Apple 的字体条款 | **不可**，只作原生运行时字体 |
| 苹方（PingFang SC） | Pomelo 里柚子的长回答和来信（Pomelo 方案）；Peck 的中文后备（Peck 方案） | macOS 系统字体，授权归 Apple，用法同手札体 | **不可**，只作原生运行时字体 |
| IBM Plex Sans | Peck 的说明、正文（Peck 方案，Google Fonts） | OFL 1.1 | 可 |
| Doto | Peck 的数字、标签、按钮（Peck 方案，Google Fonts） | OFL 1.1 | 可 |
| 缝合像素 12（Fusion Pixel 12） | Peck 的名字、标题（Peck 方案）。文件在 `schemes/peck/type/fonts/`：TakWolf/fusion-pixel-font 2026.10.25 版的 12px proportional zh_hans woff2，带 OFL 原文（2026-11-09 站主同意下载） | OFL 1.1 | 可 |
| Departure Mono | Peck 的代码、路径、命令（Peck 方案）。文件在 `schemes/peck/type/fonts/`：1.500 版 woff2，带 OFL 原文 | OFL 1.1 | 可 |

站主私人页面使用的字体与素材有各自许可，不在本仓库范围内。
