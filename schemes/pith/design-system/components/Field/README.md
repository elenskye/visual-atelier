# Field

输入框（1.1.0）。`pith-field`：纸面（`color-surface`）描一圈 `line-2`，点进去描边变海蓝、外面一圈很淡的海蓝光；多行的 `<textarea class="pith-field">` 用衬线。小一号 `pith-field--s`。

**搜索** `pith-search`：胶囊，前面是 `icons/search`，点进去伸长一点（250 → 320）；清空是一个小 ×（`pith-search-x`）。

**就地改的字** `pith-inline`：平时就是字，悬停一层淡底，点进去换成海蓝描边的框（`is-editing`），Enter 或离开时存；空的 `is-empty` 用最淡的字，锁住的 `is-locked`。
