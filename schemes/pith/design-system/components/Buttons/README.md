# Buttons

按钮少：只在要你拍板的地方（问题卡的选项、Word 修订预览上的「应用」）。主按钮是强调色的胶囊（`pith-button`），另一个是安静的（`pith-button--quiet`）。悬停一道亮光从左扫过、箭头往前挪 2px（`pith-sweep`）。

链接：强调色的字、无衬线粗体（`pith-link`），悬停上浮 1px、珊瑚色下划线从两端收拢。

小一号的 `pith-button--s`（面板里、弹窗里的小动作）；删除这类危险的 `pith-button--danger`（绯红）；危险的链接 `pith-link is-danger`。不能点的按钮变淡（`:disabled`）。
