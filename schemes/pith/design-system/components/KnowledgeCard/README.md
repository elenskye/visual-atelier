# KnowledgeCard

知识库卡片：上面类型标签（十种记录各一个图标，第二色、小号大写），标题（衬线，字重跟着生长阶段 300 → 430 → 640），一句，底下阶段图标和日期。知识库不写阶段的名字。

**写法**：`<div class="pith-kcard pith-lift"><span class="pith-kcard-label">类型图标 摘抄</span><b class="pith-kcard-title">…</b><p class="pith-kcard-line">…</p><span class="pith-kcard-meta">阶段图标 读《国富论》 · 11 月 4 日</span></div>`。悬停抬起来（`pith-lift`）。
