# DeliveryCard

交付卡：回答的成果（概念卡、调查报告、WonderLab 作品……）。左边生长阶段，中间标题（字重跟着阶段长）和一句话，右边「存进……」。

**写法**：`<article class="pith-deliver">阶段图标<div><b class="pith-deliver-title">…</b><p class="pith-deliver-desc">…</p><p class="pith-deliver-meta">…</p></div><a class="pith-link">存进「读《国富论》」 →</a></article>`。
- 点「存进……」：种子沿弧线落到顶栏的知识库图标（`save-grow`），卡上换成 `.pith-deliver-ok`：「存进知识库」的 Agent 图标加 `once`（埋进土里、长出小枝丫，停在长好的样子），后面「已种下」。
