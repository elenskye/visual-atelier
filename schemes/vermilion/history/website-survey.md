### 读回后当面确认（2026-10-31）

- **内容图标归 Vermilion，只在网站上显示。** 本仓库出图标、图标清单与 Markdown 写法，网站负责显示；Pomelo「呦呦漫游」编辑器的图标选择器在 Pomelo 仓库里另做，复制一份清单过去，只插入图标名。Pomelo 自己的界面不用这套图标。
- **职业页的 ❗ 等图标集做好后换成「提示」图标**，在做图标集的 Phase 里一起换，之前不动。这条取代 Q16 的「改成普通文字」。
- **第一次同步前 git init，按 tag 发版。** 站主 git init、提交、打 tag，Agent 按 tag 在 Mac 上构建再复制到网站。

### 之后的调整（2026-11-01）

站主验收 Phase 5 时，在网站上看过实际效果后改定两条：

- 页头左上角只放 Logo A 标志，不放名字（取代 Q13「换成字标」）。
- 网站不放分区装饰，页头留白（取代 Q5 里的「再加主页面页头的分区装饰」与 Q6）。Q12 的「每次打开网站只写一次」改用在首页数量徽标的计数上。
