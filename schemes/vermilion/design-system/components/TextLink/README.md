# TextLink

文字链接：常态是青绿文字、没有下划线；悬停或聚焦时文字变朱红、上浮 1px，1.5px 青绿下划线从两端向中间收拢。这是网站最核心的交互语言。

**三种写法，同一套效果**：

- `.text-link`：正文里的链接。放在 `.prose` 和 `.page-intro` 里的 `a` 自动套用，不用加类名。
- `.quiet-link`：段落之外的独立链接（如「查看全部」），`inline-flex`，可以在文字后面跟一个小图标（间距 `space-2`）。
- 页脚链接 `.footer-col a`：常态是 `color-muted`，悬停效果相同，见 SiteFooter。

**数值**：常态文字 `color-accent-strong`，下划线 `color-accent`；下划线收拢 220ms，上浮与变色 160ms；减弱动效时只变色、不位移、不过渡。

**动效零件**：`motion/link-underline/`（`calm`）是同一个效果的单独写法（`.va-link`），用在网站之外（例如动图）；与网站逐像素一致。

**使用方提供**：链接文字与地址。外链在新窗口打开时加 `rel="noreferrer"`。

**不要**：给链接常态加下划线或背景；用朱红做常态链接色；把整段文字做成链接。
