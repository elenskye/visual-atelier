# LoadingEnso

加载圆相：一张纸圆淡入，一笔圆相顺着写出，朱红点抵达，停一下再淡出，循环。图形语言「笔势与纸片」里唯一会循环的图形。

**结构**：`div.va-loading-enso`（`role="status"`、`aria-label="加载中"`）里放内联 SVG（132 网格），标记取 `motion/loading-enso/loading-enso.fragment.html`。显示 64px；需要文字时放在圆相下方，`text-sm`、`color-muted`。

**节奏（expressive，登记表面 `loading-enso`）**：1800ms 一圈——纸圆淡入（0–16%）、写出（10–56%）、朱红点抵达（56–66%）、停留、淡出（80–100%）。减弱动效时循环停止，只显示静止的纸圆与圆相，不显示朱红点。

**用在**：页面或面板在等待数据时。等待结束就移除，不留在页面上。

**不要**：放在正文旁边；在一屏里放两个；把它当装饰常驻；改成转圈的旋转动画。
