# DESIGN.md（Vermilion 朱红）

本方案的视觉基线与待确认设计点，站主 2026-10-23 批准（规则提炼自个人网站，此后以本文件为准）。§4「笔势与纸片」与 §5 登记的 `expressive` 表面 2026-10-26 写入，站主 2026-10-30 批准。2026-10-31 起本方案只用于个人网站，原先写给 Pomelo 的条目已移出。任何视觉改动前必须完整阅读。数值写在 `tokens/`，本文件只写规则。

## 1. 方向

- 用在：只用于个人网站 elenskye-website（双语，服务招聘展示与社交介绍），以及站主以同一身份对外使用的 PPT 与动图。核心身份「尘世漫游」。
- 不用于 Pomelo：Pomelo 另建了自己的方案与 Design System，不取用本方案的 token、规则与资产（2026-10-31 站主决定）。唯一的例外是网站内容用的内容图标（§6）：Pomelo「呦呦漫游」编辑器复制图标清单，只用来给网站内容插入图标名，Pomelo 自己的界面不用。
- 网站优化的取向（2026-10-31 问卷）：优先照顾朋友与读者，偏向有个性、有记忆点；招聘方需要的清楚与可信是底线。
- 气质：清醒独立、暖纸冷青、朱红重点、充足留白、克制的编辑感与版画感。
- 不要：SaaS 感、霓虹、玻璃拟态、重阴影、过量渐变与圆角。内容先于装饰。
- 视觉资产由站主与 AI 协作完成；不默认站主会画图。

## 2. 色彩

取值见 `tokens/color.json`，要过的对比度配对见 `tokens/contrast.json`。

- 七个角色：页面、分区、表面、正文、次要文字、结构（青绿，常态与强两档）、交互（朱红）。派生三个：结构线、弱结构线、结构色浅底。
- 青绿管结构与常态链接；朱红只用于悬停、选中、数量与焦点，不作大面积装饰。焦点色就是朱红。
- 暗色模式是深青底加暖白字，不是纯黑。
- 七个角色的分工未经批准不得改变；改色须在明暗两种模式都过 APCA。

## 3. 字体与排版

字体清单见 `type/fonts.json`，字号与字体栈见 `tokens/scale.json`。

- 标题与长文：Source Serif 4 + Noto Serif SC；正文与界面：Work Sans + Noto Sans SC。全部自托管、可再分发。
- 中英文页的拉丁字形都用 Source Serif 4 / Work Sans；页头页脚用无衬线，页脚主标题用衬线。
- 大标题桌面最大 `4.2rem`、移动端 `2.9rem`；字号阶梯 `0.82 / 0.94 / 1 / 1.18 / 1.5rem`。
- 标题允许安全断词与平衡换行；正文阅读宽度窄于主内容区。

## 4. 图形语言

### 版面

- 主内容最大宽度 `1240–1320px`；间距只用 `tokens/scale.json` 的九档（4–96px）。
- 圆角 `6–8px`（圆形控件除外），只用轻边框或色块；横线只用在页头底部与页脚顶部；阴影只用一档柔和阴影（图片卡片悬停时略加深）。
- 点击目标至少 `44 × 44px`；焦点必须清楚；状态不能只靠颜色表达。

### 控件

- 标签（Topic）按自然文字宽度排列，视觉间距 `24px`。
- 圆形按钮：可见圆圈 `30px`（`1px` 结构线，悬停变结构色），透明点击区扩到 `44px`。
- 社交入口：`44px` 点击盒紧挨着排、不加间距，可见图形 `24px`。
- 图片画廊：同色无框的固定三联画区域，主图完整等比显示，侧图点击后滑入中央，横竖图切换时页面不移动；放大态只显示当前这张，完整适配视口。

### 母题

- **漫游路径**：点状虚线路径加终点圆圈。见于 Logo A 与小标题前的小图标（`marks/route-glyph.svg`）。
- **时间线节点**：`13px` 空心圆（`2px` 结构色描边、页面色填充）加竖向连接线（月度时间轴用 `1.5px` 虚线，履历时间线用 `1px` 实线，结构线色）。
- **元信息分隔**：中点「·」，结构线色。
- 已定：「路径与节点」不扩展成整套图形语言系统；图形语言另立为下面的「笔势与纸片」。

### 笔势与纸片（图形语言）

> 2026-10-26 Round 3 写入，站主 2026-10-30 批准（大图墨感同日定为「提按」）。数值见 `tokens/graphic.json`，资产在 `marks/graphic/`，由 `tooling/graphic/` 生成；探索经过见 `history/exploration-brief.md` 的探索日志。

一句话：**两头收尖的笔，叠在柔软的纸上。** 灵动、自在、以线条为主；不老气、不僵硬、不单调。

**构成**
- 每个图形 = 1–3 张纸片 + 1–3 笔笔势（加载动画只一笔）。笔势是骨，纸片是底，二者都必须有。
- 纸片在下、笔势在上；两者不同心，纸片错开图形宽度的 5–8%，笔势可以越出纸片。
- 大图（分区装饰、分享图、文章题图、空状态、PPT）的纸片贴着画面下缘或一角出血，像叠起的远山；文字一侧留空，留白不少于画面的 40%。

**笔势**
- 形：沿一条平滑中心线生成的填充形，两头收尖。三种收笔：两头尖（`sym`）、起笔重收笔尖（`head`）、起笔尖收笔重（`tail`）。最细处不小于最粗处的 12%。
- 粗细：图标在 64 网格上，主笔最粗 5–6.2，次笔 3.2–4.2，细笔 2.6–3，圆相 7–8。大图按画面短边取：主笔 3.3–4.5%，次笔 1.5–2.3%。
- 笔数随尺寸：显示 ≥ 48px 用 2–3 笔；≤ 32px 换成 1–2 笔的简笔版，纸片不变。
- 墨感：分类图形、加载动画等小图（≤ 160px）用光洁的边；宽 ≥ 400px 的大图用提按——不加纹理，笔在行进中按下、提起、再按下，一笔里粗细起伏一到两次，最细处约为最粗处的 62%；边仍然光洁。不用飞白、不裂缕、不加鬃丝纹理。
- 颜色只用结构色 `accent`（暗色取它的暗色值）；不用正文色，不用朱红画笔势。
- 方向：从左下往右上、或顺时针绕；书写方向就是动画方向。

**纸片**
- 形：柔软的有机形（圆、叶、山、书页），边缘是平滑曲线；画廊类可用圆角矩形。没有描边、阴影、渐变、半透明叠色，也不贴纹理位图。
- 颜色取「与所在底色相邻的一层面色」：放在页面底上，浅色用分区色 `surface-cool`、暗色用表面色 `surface`；放在表面底上（卡片悬停、空状态框、面板），两种模式都用分区色 `surface-cool`。需要第二层纸时用结构线色 `line`。
- 这是三种面色与结构线色作填充面的新用法，只用于本图形语言，不改变它们原有的分工。

**朱红**
- 静态图形里没有朱红。朱红只在交互「抵达」那一刻出现：一个小圆点（64 网格半径 2.4–3），落在最后一笔的终点或图形中心，动效进行到 82% 之后才出现，离开即消失。它是 Logo A「圆圈变红」的延伸。

**尺寸与网格**
- 图标画在 64 网格上，四周留 4 个单位，纸片可以出血到网格边缘。
- 24px 是简笔版的检验尺寸：缩到 24px 仍要分得清类别。

**用到别处（迁移规则）**
- 无封面卡片：类别图形 44px（三笔版），放在标题左侧，替代 Lucide 类别图标（`pen-line` 等）。类别：写作、项目、画廊、创作、游记、其他；网站目前只用前四类，游记、其他留作备用（2026-10-31）。卡片悬停出现表面色时，纸片跟着改取表面底上的颜色（`va-on-surface`）。
- 页头分区装饰：网站不用，页头留白（2026-11-01 站主改定；2026-10-31 曾定放首页、当下、站内搜索三页）。分区装饰与它的入场动效留给 PPT、动图等别处。
- PPT（16:9，按 1920 × 1080 画）：封面用纸山 + 提按长笔 + 圆相，标题放左上留白处；章节页用一笔提按作标题下的横线，编号用衬线字、结构色。
- 加载：纸圆淡入 → 一笔圆相写出 → 朱红点抵达 → 淡出，循环；数值见 §5。
- 404 插图「折页」（站主 2026-11-02 批准，VL1 Phase 7）：一张地图纸从左下角出血、右上角折起一角（第二层纸），一笔提按冲出纸边停在空白里，一个没合上的圆相落在纸外——「走到了地图之外」。640 × 400，提按；放在 404 页标题与说明下方，最宽 `560px`，打开页面时用描边绘制写一次（§5）。
- 文末落款（站主 2026-11-02 批准，VL1 Phase 7）：文章正文结尾的一个小图形，64 网格、光洁，显示 `40px`、居中，三版每次打开文章随机显示一版（站主定）：
  - 抵达 `end-mark-arrive`：一笔从左下走到一个小圆相前，是 Logo A「走到终点」的笔势版；
  - 远山 `end-mark-hills`：低低的纸山、一笔地平线、一个小圆相作太阳，是分享图与空状态的缩小版；
  - 三点 `end-mark-dots`：三个短笔由重到轻、由长到短，像文末的三点（dinkus）；不排成等距的虚线。
  - 落款第一次滚进视口时用描边绘制写一次；只放在有正文的文章里（英文页里只链向中文原文的占位页不放）。
- 文章分享图「低山」（站主 2026-11-02 批准，VL1 Phase 9）：每篇文章一张，1200 × 630 浅色 PNG，由消费方构建时按标题自动生成，发文章不用手动做图。数值见 `marks/derived.json` 的 `og-card`。
  - 版式：纸山压低、贯穿全宽，一笔提按贴着山脚走，圆相在右上角（`og-card-graphic`）；字标在左上（标志 `accent-strong`、名字 `text`）；标题 `text`、左对齐，放在纸山上方，最后一行基线固定，行数多了往上长。静态，没有朱红。
  - 字体：Source Serif 4 + Noto Serif SC，按字符取字，顺序与网站的衬线字体栈相同；字重 600，比网站大标题的 400 重，因为转发预览里图会缩到三分之一左右。
  - 长标题：字号四档，取第一个放得下的；同样的行数里挑最匀称的断法，偏向在冒号、分隔符、句读后面断；标点守禁则，不落在行首或行尾；单词放不下才拆开。最小一档还放不下，就停在省略号上。
  - 字体里没有的字（如 Emoji）不画，不出现豆腐块。标题连一个能画的字都没有时，只留底图与字标。
  - 同一标题、同一份模板与依赖，两次输出逐字节一致。文件名带标题的短哈希，改了标题就换地址，转发平台才不会一直显示旧图。

**资产与用法**
- 源文件在 `marks/graphic/`：分类图形六类各两版（`glyph-<类别>.svg` 三笔版、`glyph-<类别>-simple.svg` 简笔版）、分区装饰 `section-deco`、分享图底图 `og-graphic`、空状态 `empty-graphic`、PPT 封面与章节页底图 `ppt-cover` / `ppt-section`、加载圆相静止帧 `loading-enso`、404 插图 `not-found`、文末落款 `end-mark-arrive` / `end-mark-hills` / `end-mark-dots`、内容图标 `icon-<名字>`（§6）、文章分享图底图 `og-card-graphic`。
- 文章分享图的模板是生成的 `marks/og-card/template.json`（底图与字标已上好色，由 `tooling/marks/derive.mjs` 生成），生成模块是 `tooling/og-card/card.mjs`，两者一起同步到网站。
- 源文件不写死颜色：笔势与纸片各用一个角色变量（`--va-ink`、`--va-paper`、`--va-paper-2`），内联到网页时引入 `marks/graphic/graphic.css` 并给图形加 `va-graphic`。要用 `<img>`、贴进幻灯片或做分享图时，用构建产物里上好色的 `themed/<id>-light.svg` / `-dark.svg` 或 PNG。
- 不手改这些 SVG：改几何或参数就改 `tooling/graphic/` 与 `tokens/graphic.json`，再运行 `npm run build:graphic`；已批准的图形生成器拒绝覆盖，要改开新版本。

**不要**
- 不写汉字笔画、不仿书法字、不做印章篆刻、不泼墨、不晕染、不加宣纸纹理；不把「路径与节点」的虚线混进来。
- 纸片不作卡片背景、不铺满整屏；笔势不作分隔线（页头底线、页脚顶线仍是仅有的横线）。

### 图像

- 优先用站主真实的摄影、绘画与作品；AI 图像不得伪造站主肖像或冒充原创。
- 图片 ≤ 1.5 MB，其他公开文件 ≤ 5 MB。
- 默认分享图：v3 `marks/illustrations/og/default-v3.svg`——分享图底图加字标（标志 `accent-strong`、名字 `text`）与副题「呦呦漫游 · Wander」（`muted`），由 `tooling/marks/derive.mjs` 生成，导出 1200 × 630 浅色 PNG（站主 2026-10-31 批准）。网站自 VL1 Phase 5 起换用；旧的 `wander-og-v2` 位图留档。
- 文章分享图：每篇文章用自己的（§4「文章分享图」）；有封面的文章也用它，不用封面（站主 2026-11-02 定）。其他页面用默认分享图。
- 作品水印（站主 2026-11-02 批准，VL1 Phase 10）：画作与摄影上线时在角落加一个小字标。数值见 `marks/derived.json` 的 `watermark`，生成模块是 `tooling/watermark/watermark.mjs`。
  - 样式「字标」：Logo A 标志加名字（`logo-lockup` 转曲线），只用一种颜色，高度是短边的 3.4%，面积不超过画面的 1.5%。不加底板、不做印章、不斜铺满画面。
  - 位置：默认右下角，离边缘是短边的 2.8%；右下角明显比左下角杂乱时自动换到左下角，免得压在细节上。
  - 取色：量水印所在那一小块的亮度，取对比度高的那种墨：亮处用 `text` 的浅色值（深墨），暗处用 `text` 的暗色值（浅墨）。不透明度 82%，下面垫一层很淡的反色柔光，在杂乱的画面上也认得出。不用青绿，不用朱红。
  - 范围：作品页 `gallery` 里的图和关于我页的「画作与摄影」，已上线的也包括（站主定）。第三方照片、文章正文图、封面与卡片小图、肖像不加；短边小于 480px 的不加。
  - 原图不动：资源库里存原图，网站构建时生成带水印的版本（站主定），所以改样式或撤掉只要重新构建。不保留 EXIF（包括拍摄地点），保留色彩配置。
- 空状态用矢量的 `empty-graphic`（VL1 Phase 5 起）；404 用矢量的 `not-found`（VL1 Phase 7 起），旧位图 `wander-error-cloud-pages-404` 留在 `marks/illustrations/` 存档。插图外背景必须透明。

## 5. 动效

数值见 `tokens/motion.json`，档位的含义见 `docs/motion-tiers.md`。

- 默认 `calm`：状态变化 `160–220ms`，入场 `320ms ease-out`；不用视差、循环、弹跳、页面转场；只动位移与透明度。
- `expressive` 只能用在已登记的表面（见下）：单次 ≤ `1200ms`（站主 2026-11-02 定案）；每屏最多一个，与正文同屏时正文不动；只动 `transform`、`opacity` 与 SVG 描边；窄屏掉帧时降级为 `calm`；循环只能在访客在场时运行、可暂停、不出现在正文旁边。
- 两档在减弱动效时都回到静态终态，循环停止；键盘与读屏路径不依赖动效。
- 招牌动作（`calm`）：Logo A 的虚线延伸 → 到达 → 圆圈变朱红，`520ms`，见 `motion/logo-route/`。
- 已登记的 `expressive` 表面（站主 2026-10-30 批准；网站只用这三个，不再登记新的表面，2026-10-31 问卷；数值见 `tokens/motion.json` 的 `registeredSurfaces`，实现见 `motion/` 下的同名零件 `category-glyph-hover`、`section-deco-intro`、`loading-enso`）：
  - 分类图形悬停（悬停或键盘聚焦触发）：纸片 `260ms` 滑入，笔画每笔 `340ms`、相隔 `100ms` 按书写方向写出，朱红点在 82% 之后抵达；整段 ≤ `700ms`。卡片的上浮、标题变色仍按 `calm`。
  - 分区装饰入场：每次打开网站只写一次，同一次访问里站内跳转或刷新直接显示终态（2026-10-31 站主定；页面 `<head>` 里运行零件的 `section-deco-intro.once.js`）；≤ `1200ms`，之后静止；每屏只此一处。网站自 2026-11-01 起不放分区装饰。
  - 加载圆相：`1800ms` 一圈循环——纸圆淡入（0–16%）、写出（10–56%）、朱红点抵达（56–66%）、停留、淡出（80–100%）；只在等待时出现。
  - 减弱动效时：悬停与入场直接显示终态；加载只显示静止的纸圆与圆相，不显示朱红点。
  - 实现：笔画用遮罩里沿中心线的描边来「写」（`pathLength="1"`，`stroke-dasharray: 1 2`，偏移从 1 到 0）；实时版与 GIF 同源，GIF 逐帧定格 `document.getAnimations()` 导出。
- `calm` 零件（站主 2026-11-01 批准，VL1 Phase 6；实现见 `motion/` 下同名零件）：
  - 链接下划线收拢 `link-underline`：悬停或聚焦时文字从青绿变朱红并上浮 `1px`（`160ms`），`1.5px` 青绿下划线从两端向中间收拢（`220ms`）。导航用同款下划线（画在 `::after` 上）。提取自网站，与网站逐像素一致。
  - 选中指示滑移 `selection-slide`：单选项下方一条 `1.5px` 青绿下划线，换选时滑到新选中项（位移与横向缩放 `220ms`），取消选中时淡出（`160ms`），第一次选中时原地淡入。用在首页话题栏；顶部导航是整页跳转，不滑。
  - 数字计数 `count-up`：数字徽标从 `00` 数到实际值（`320ms` ease-out），等宽数字；每次打开网站只数一次（共用标记 `motion/visit-once.js`）。用在首页的数量徽标。
  - 描边绘制：「笔势与纸片」图形按笔顺画出，纸片淡入、笔画依次写出，没有朱红点。给不在登记表面上的图形用。现行版本 `stroke-draw-v2`：整段 `640ms`（纸片淡入 `320ms`，每笔分到 `640ms / 笔画数`）。初版 `stroke-draw`（`320ms`）站主看过后嫌太快、看不清笔顺，比较 `320 / 480 / 640 / 800 / 1000ms` 后选定 `640ms`（2026-11-01）；初版留档，网站没有用过。
  - **calm 时长例外**：描边绘制超过 calm 入场的 `320ms` 上限，站主 2026-11-01 批准为例外（`tokens/motion.json` 的 `calmExceptions`，只适用于登记在里面的零件）；其余仍按 calm：不循环、不用朱红抵达、减弱动效时静态。再加例外须站主批准。
  - 用描边绘制的两处（站主 2026-11-02 批准，VL1 Phase 7）：404 插图入场 `not-found-intro`，打开页面时写一次，不需要脚本；文末落款 `end-mark`，`end-mark.js` 每次打开文章随机挑一版，落款第一次滚进视口时写一次，打开页面时已在屏幕里的直接静态显示；减弱动效时都直接显示完整图形。
  - 不做逐行显现（2026-10-31 问卷）。
- 在用、还没做成零件的 `calm` 模式：控件的颜色与边框 `160ms`，位移与背景 `180ms`。

- 分类图形（`marks/graphic/glyph-*`）：64 网格，≥ 48px 用三笔版、≤ 32px 用简笔版；规则见 §4「笔势与纸片」。无封面卡片里替代 Lucide 的类别图标。
- 字标 `logo-lockup.svg` 含文字（Noto Serif SC 600），本身不导出 PNG。转曲线的版本由 `tooling/marks/derive.mjs` 生成（Noto Serif SC 是 OFL，可以转；站主 2026-10-31 批准）：整套字标 `logo-lockup-paths.svg`，只含名字的 `wordmark.svg`。

- 网站界面的通用图标（分类图形与内容图标之外）用 Lucide：`16 / 20 / 24px`、线宽 `1.8`；按钮提供 `aria-label`，不用 Emoji 代替。
- 内容图标（站主 2026-11-02 选定，VL1 Phase 8）：写进网站内容、替代 Emoji 的小图形，24 个。清单是生成的 `marks/icons.json`（名字、中英文标签、关键词、可内联的 SVG），写法说明在 `marks/icons.md`。
  - 画法：简笔加纸片。64 网格，一张纸片加 1–2 笔光洁的笔势，按 §4 画。笔比分类图形的简笔版略粗（最粗处 6–10.5），在正文字号里才分得清。静态，不用朱红，不做动效。
  - 颜色：笔势用结构色 `accent`，纸片按 §4 取所在底色相邻的一层面色。笔势放在页面、卡片、纸片（分区）上都过 APCA Lc ≥ 60（`tokens/contrast.json`）。放在链接或按钮里时，悬停的笔势跟着文字变色（正文链接变朱红，按钮仍是结构色强），在悬停底色 `accent-soft` 上也过 Lc ≥ 60。
  - 尺寸：跟着字号走，约 `1.2em`，基线略下沉，两侧各留一点空隙。24px 是检验尺寸。
  - 写法：Markdown 正文与 frontmatter 文字字段里写 `:名字:`。只认清单里的名字，其他冒号写法原样保留；代码里不替换。
  - 读屏：读出图标的标签，中文页读中文，英文页读英文。图标只是点缀，句子本身要能读通。
  - 和 Lucide 分工：Lucide 管网站界面自己的通用图标，即导航、按钮、搜索、社交入口与卡片上的控件。内容图标只出现在内容里，由写内容的人选用。两套不混用：界面不用内容图标，内容里不用 Lucide，也不用 Emoji。
  - 加图标：在 `tooling/graphic/icons.mjs` 加一项，重新生成。已批准的图标不改，要改就开新名字。
