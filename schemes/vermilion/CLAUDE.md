# CLAUDE.md（方案）

继承仓库根目录的 `CLAUDE.md`。本方案的气质、禁用项、色板与动效数值以同目录 `DESIGN.md` 为准；与根规则冲突时，以根规则为准并告知站主。

`AGENTS.md` 是指向本文件的软链接。

- 改任何视觉基线前，先完整阅读 `DESIGN.md`。
- `approved` 的资产不改几何与参数，要改开新版本。
- 本方案的 token 与规则不得借用其他方案。
- Design System 只从本目录生成：改 token、规则、组件或资产后，改 `design-system/` 与相关源文件，重建并按 `tooling/README.md` 发布；不在 Design System 页面上直接改。`DESIGN.md` 的规则变了，`design-system/README.md` 与对应组件说明要一起改。
- `DESIGN.md` 没写到的决定（网站接入的细节、谁在什么时候定的）查 `history/`，定过的不重复询问站主。
