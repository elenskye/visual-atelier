# Stickers

通用贴纸，34 张，64 格（视口 `-8 -8 80 80`，白边和投影在里面），画法和模块贴纸一样。

- 32 张给自建模块和标签挑（站主 2026-11-08 要的：每个模块都能换图标和颜色）：前 23 张对应自建模块原来能选的图标，后 9 张是加的（猫咪、小花、灵感、小家、健康、信封、存钱、骰子、月亮）。文件名就是 Pomelo 里的名字。
- `settings.svg`、`calendar.svg`：设置和日历的贴纸，不进「图标和颜色」的挑选。
- 这里是蓝笔浅色上好色的版本；源文件在方案的 `marks/modules/`、`marks/places/`，颜色是变量，要换分类色就在外面设 `--mark-color`。
