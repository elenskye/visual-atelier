# Pomelo

柚子：唯一的角色，就是 AI。线描贴纸：墨线描边、柚黄填色错开一点、外面一圈白边、轻投影。

- `pomelo-normal.svg` … `pomelo-wow.svg`：8 个表情的静态帧（平常、在想、眨眼、困了、开心、出错、惊讶、哇），100 格（视口 `-6 -6 112 108`，想法泡泡、星星、「!」、z 都在里面）。这里的是蓝笔浅色上好色的版本；源文件在方案的 `marks/pomelo/`，颜色写成 `var(--pm-角色, var(--color-角色))`，内联进挂了本系统的页面就跟着配色和明暗走。
- `ai-button.svg`：「问柚子」按钮，柚子探出头、右上角一个白色对话泡泡。Pomelo 顶栏右边按 34 号放。
- 柚子的墨色只用实心小点，不和错开的填色叠在一起；不改五官的位置和线宽。表情动画还没做。
