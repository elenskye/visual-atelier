# Modules

模块贴纸，21 个，64 格（视口 `-8 -8 80 80`，白边和投影在里面）。行内 24 / 26 / 30，置顶和桌面下排 40–60；16 号太小，不用。

- 每个填一种分类色，跟模块坞的分类走（站主 2026-11-07 定）：薄荷「日常」`todo` `notes` `articles` `days` `finance` `packing`；樱粉「兴趣」`books` `films` `drawing` `site` `canvas`；葡萄紫「求职」`jobs` `seeker` `rater`；橙「柚子」`translate` `pub2md` `importer` `atlas`；天蓝「工具」`vault` `bookmarks` `janitor`。柚子模块用柚子本人（Pomelo 里的 `pomelo-normal.svg`）。
- 文件名就是 Pomelo 里模块的 id（`articles` 是「见字如面」，`canvas` 是「有板有眼」，`atlas` 是 Atlas）。这里是蓝笔浅色上好色的版本；源文件在方案的 `marks/modules/`，颜色是变量。
- 自建模块（五花八门、循序渐进）和标签能挑的 32 张通用贴纸在 Stickers。
