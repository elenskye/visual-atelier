# Icons

界面小图标，168 个，替换 Lucide：24 格一笔单线、线宽 2、抖动 0.32，没有填色和白边。

- 文件名就是图标名，大多沿用它替换的 Lucide 名字（`plus`、`search`、`trash-2`……）；新起名字的有 `pomelo`（柚子，替换原来的小鸟和柑橘）、`back-desk` 回桌面、`flip` 翻面、`time-travel` 时间穿梭（Atlas 里一年的封面下面）。
- 线是 `currentColor`，用的地方定颜色：正文里跟 `color-ink`，图标按钮里是 `color-pen`，删除是 `color-danger`。大小 16、20、24。
- 选中时底下抹一笔荧光笔，不加方框。这一套里没有的，按 Icon 组件的画法用 `data-hand="icon"` 画，别拿通用的细线图标。
