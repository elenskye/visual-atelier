# Stat

统计数字和问候：手札体粗，数字等宽（右对齐就齐，表格里不换字体）。大的金额 `stat-lg` 30，倒数和计数 `stat` 20，问候 `greeting` 46。要紧的一个数（还有几天、今天的问候）底下垫一笔荧光笔。

**写法**：`<span class="pm-stat">还有 <span class="pm-stat-num">12</span> 天</span>`；大号加 `pm-stat--lg`。涨了用 `pm-up`（`color-up`），跌了用 `pm-down`（`color-ink-soft`），不用红。荧光笔见 PenMarks。数字出现时从 0 数上来（动效零件另做）。

**用在**：资产、记账、倒数日、读了几本、打卡天数；首页的问候「下午好呀」。

**使用方提供**：格式化好的数（`¥186,420.55`、`1 / 3`）和前后的短字。数字和汉字之间空一格。

**不要**：一屏抹好几处荧光笔；跌了用红色；统计数字用细体或换字体。
