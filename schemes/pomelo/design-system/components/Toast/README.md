# Toast

提示：一张便签纸（200 × 80）啪地贴在窗口右下角，歪 −3° 左右，上面一条胶带；过一会儿自己撕走（动效零件另做）。

**写法**：`<div class="pm-toast" data-hand="note" data-tilt="-3" data-tapes="1" role="status">存好啦</div>`。纸 `color-sticky`、字 `color-on-sticky`（17 粗）、投影 `shadow-card`。可以带一个能点的「撤销」（下划线，颜色同字）。

**用在**：存好了、丢掉了这种做完一件事的回应。

**使用方提供**：两三个字的回应（「存好啦」「已丢掉 · 撤销」）。

**不要**：一次贴好几张；写成句子；用它报错（出错时柚子摇头，写在出错的地方）。
