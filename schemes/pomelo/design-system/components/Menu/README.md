# Menu

右键菜单：一条纸（和下拉展开的那条一样，两侧笔色的边、格子之间虚线），只是矮一点（一格 30）、带一点投影。最上面是最常用的一两项（加粗、开头一个笔色的图标）；一道笔色的线隔开；下面是一组一组的（「文字」「段落」「插入」「提示框」），右边一个小箭头，指着或点它，旁边再出一条纸列这一组。快捷键写在右边，次要文字色。

**写法**：`<div class="pm-menu pm-menu--ctx" role="menu">`，每格 `<button class="pm-menu-item" role="menuitem">`；加粗的那几格再加 `pm-menu-lead`；隔线 `<div class="pm-menu-rule">`；组的那一格 `aria-haspopup="true"`，指着时加 `is-on`（选中色）；旁边那条 `<div class="pm-menu pm-menu--ctx pm-menu-sub" role="menu">`，贴着那一格的右边，放不下就在左边。快捷键 `<span class="pm-menu-keys">⌘B</span>`。

**用在**：写字的框里右键（见字如面、念念不忘、写提示词的框）、格式条的「更多格式」；列表的一条、对话、消息上右键是同一种纸。

**使用方提供**：最上面几项、各组和组里的项、快捷键、种子。

**不要**：把所有项摊在一条里；第二条盖住第一条；用白底的浮层卡片。
