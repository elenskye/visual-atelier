# Link

柚子链接：写字时用 `[[…]]` 链到 Pomelo 里的另一样东西（笔记、文章、书、电影、游戏）。三种样子，颜色都是柚子链接色 `color-link-pomelo`（网页的链接还是 `color-link`）：

- **小卡**（`[[目标]]`）：行内的一小块，柚子链接色的淡底（9%，指着 16%），圆角 7，开头是那个模块的贴纸（和字一样高），后面是名字；不换行。找不到的那一条用次要文字色、灰的底。
- **字**（`[[目标|字]]`）：只有那几个字是柚子链接色，下面一条点线（1.5，离字 3）。
- **列表**（「柚子链接 · N」、链到这里的）：大一号的小卡（14，行高 1.8），后面跟一句灰的说明（哪个模块、哪天）。

**写法**：`<span class="pm-lk"><span class="pm-lk-mk" data-hand="icon" …></span>名字</span>`；字 `<span class="pm-lkw">几个字</span>`；列表加 `pm-lk-lg`，说明 `<span class="pm-lk-d">`；找不到的加 `dead`。Pomelo 里贴纸是那个模块的贴纸（这里拿界面小图标代替）。

**用在**：念念不忘、见字如面的正文和卡片、书影游面板的「柚子链接」一栏、文末的「柚子链接 · N」。

**使用方提供**：目标的模块、名字、种子。

**不要**：用下划线的网页链接样子画小卡；一行里放太多小卡（一条笔记三五个以内）。
