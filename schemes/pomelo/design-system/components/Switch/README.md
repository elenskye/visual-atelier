# Switch

开关：54 × 30 的手画轨道，开的时候荧光笔把轨道涂满、圆贴纸的钮滑到右边。

**写法**：`<button class="pm-switch" role="switch" aria-checked="true"><span>开机自动启动</span><span data-hand="switch"></span></button>`。开还是关只看 `aria-checked`：荧光笔 `color-marker`、钮是 `color-art-white` 加笔色的边。整行可点，高 40。

**使用方提供**：一句说清楚开了会怎样的短字（「开机自动启动」）、状态、种子。

**不要**：开关旁边再写「开 / 关」；用开关做要按「保存」才生效的设置；拿它当勾选框用。
