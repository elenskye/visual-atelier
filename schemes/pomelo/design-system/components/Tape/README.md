# Tape

胶带：两种，薄荷斜条纹（`color-tape-mint-a/b`）和柚黄斜条纹（`color-tape-yuzu-a/b`），45°、每条 7px，两端锯齿，半透明（0.88）。

**写法**：贴在卡片、便签、纸上：给它们加 `data-tapes="1"` 或 `"2"`，`Pomelo.paint` 按种子贴。第一条是薄荷，贴上边居中附近（歪 −4° 上下 3°）；第二条是柚黄，斜贴一个角（约 ±30°）。胶带在纸那一层里，跟纸一起歪，压不住字。不在页面上时用 `Pomelo.hand.tapes(宽, 高, 种子, 条数, 颜色)` 拿 HTML。

**用在**：首页的卡片、便签、照片、票根，标签的底。

**使用方提供**：条数（1 或 2）、种子。

**不要**：一张卡片贴三条以上；胶带盖住字；换别的颜色的胶带。
