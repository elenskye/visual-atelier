# Palettes

五套配色、每套明暗：蓝笔 · 方格纸（默认）、紫笔 · 樱粉荧光、黑笔 · 牛皮纸、柚黄桌面、薄荷桌面。

**怎么切**：不写就是蓝笔。在任何元素上写 `data-palette="purple"`、`"kraft"`、`"yellow"`、`"mint"` 换配色，`data-theme="dark"` / `"light"` 换明暗；两个写在同一个元素上、或谁套着谁都行，里面的 `--color-*` 变量自动换成那一套的值，组件不用改。Design System 页上的「浅色 / 暗色」只是蓝笔的明暗。

**两个家族**：钢笔家族（蓝笔、紫笔、黑笔）笔色管线条和按钮，荧光笔管选中；色面家族（柚黄、薄荷）桌面整片上色，顶栏是墨色，深色时反过来（桌面墨色、按钮用桌面色）。

**跟着配色走的**：桌面、纸、卡面、墨、笔、主色、选中、荧光笔、链接、危险、涨、顶栏、页签、贴纸墨线。**各套共用的**：5 种分类色、柚子的颜色、胶带、便签纸、印出来的东西。

**使用方提供**：站主在设置里选的配色和明暗，写到根元素上。

**不要**：自己调一套新配色或改某一套里的单个颜色；每套明暗都过了 APCA，改色要回到方案里改。
