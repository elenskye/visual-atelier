# Input

输入框：手画的圆角框（圆角 11，笔色 1.6），纸面是卡面；聚焦时不出现额外的方框，手画的边描粗到 2.8。笔的小图标放在右边，聚焦时会晃（动效零件另做）。

**写法**：`<label class="pm-field" data-hand="field"><input placeholder="写点什么…"><span class="pm-field-icon" data-hand="icon" …></span></label>`。高 40，左右 12，字 15，占位字 `color-ink-soft`，光标是笔色。聚焦描粗是样式自己做的（`:focus-within`）；要静态展示聚焦的样子加 `is-focus`。

**用在**：记一笔、搜索（找东西）、改名字。多行的写法一样，框按内容的高度画。

**使用方提供**：占位字（俏皮、短：「写点什么…」「找点什么…」）、可选的图标、种子。

**不要**：聚焦时加蓝色的光圈或第二层方框；占位字写使用说明；框里的字贴着边（左右至少 6）。
