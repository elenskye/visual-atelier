## 过程里值得留的

- **画布重建**（2026-11-05）：另一个账号的会话读不到共享画布，拥有者账号的 Claude Code 也读不了旧画布的文件（报错说用模板建的画布有组织外账号写过就不再提供，原因没有确认）。站主删了旧的三块 Pomelo 画布，只新建 Pomelo Explore，不复现旧页，并定下规矩：画布的源必须留在本地。旧页的导出在站主本机 `~/Downloads/ELEN/pomelo-explore/`，不进本仓库；生成器在 `canvases/pomelo-explore/archive/`。
- **探索改在 Claude Code 里做**（2026-11-03）：Claude 会话打不开共享的画布，所以由程序生成样稿写进画布。
- **对比度的微调**（Phase 3）：Phase 2 小样的配色有 73 处不达标，动了 30 处颜色，只改亮度。清单在 `canvases/pomelo-explore/p3-scheme/color-changes.json`，画布「Phase 3 · 方案」的对比度页有前后对照。
- **导出时好时坏**（Phase 3 期间查到）：和 VL2 的改动无关，没改动的提交上也能复现。主要是 Chrome 的 GPU 栅格，`tooling/lib/browser.mjs` 改成固定走软件栅格；还剩一张图偶发，见 `ROADMAP.md`「Vermilion 现状」。
