# Atlas 的设计

Atlas 是 Pomelo 里把柚子写的年度总结做成「看得见的一年」的模块。这里放它的设计：怎么照一份数据把这一年画出来、动起来。Pomelo 只管数据（每次运行存一份「呈现结果」）和把设计挂出来，画什么全在这里。

站主定的规矩（2026-11-10、11-11）：

- **每次定稿都有名字和版本号**（站主敲定），并冻结一份快照。版本号三段：小修 `1.0.1`，加东西 `1.1.0`，大改 `2.0.0`；换一套全新的设计起新名字。第一轮定稿是 **Tabloid**，现在有 **1.0.3** 和 **1.1.1** 两条线（1.1.x 加了玩物有志、自建模块的一幕和见字如面的两幕）。
- **哪些算定稿**（站主 2026-11-11）：只升最后一位是小修，新的一份**替掉**同一条线（前两位一样）里旧的：1.0.0 → 1.0.1，1.0.0 就不算定稿了，只留 1.0.1 的快照。升了前两位是新的定稿，**两份都留**：1.0.3 → 1.1.0，1.0.3 和 1.1.0 都是定稿、都有快照。所以一条线只有一份快照，`--freeze` 冻结新的小修版时自动删掉同一条线里旧的，`--check` 发现一条线有两份会报出来。
- **快照不改。** 定了就不动，要改就改源、升版本、再冻结一份。
- **旧的照同一条线里最新的画。** Pomelo 里每一份年度总结记着它是照哪一版做的（`design`，比如 `tabloid@1.0.0`），画的时候用同一条线里装着的那一份（1.0.x 都用 1.0.3）；升了前两位的新定稿只给以后新做的用，旧的不跟着换。数据不改，只是画的时候这样找。
- **每一版画自己的封面**（站主 2026-11-11）：Atlas 页上一年一张的封面由设计自己画（`cover`），印着年份、这一版的名字和版本号。
- **每次运行都留着。** 2025 年做过一次，2027 年有了新设计再补做 2025，是多一份，以前那份不动。只有站主能删。

## 文件

| 路径 | 内容 |
| --- | --- |
| `tabloid/` | Tabloid 的源。`design.json` 是它的名字、版本和要打包的模块；`pages.mjs` 每一幕的页，`parts.mjs` 玩物有志和自建模块的页（1.1.0），`writing.mjs` 见字如面的两幕（1.1.1），`bubbles.mjs` 聊天页的泡泡，`shell.mjs` 舞台（信封、小报、按钮、抽屉、弹出的纸条），`cover.mjs` Atlas 页上的封面，`runtime.mjs` 交互，`style.mjs` 样子和动静，`draw.mjs`、`kit.mjs` 画页的零件，`index.mjs` 入口，`sample.mjs` 一份编的数据 |
| `releases/<名字>-<版本>/` | 冻结的快照：`design.js` 一个文件（设计的全部代码、画好的柚子和贴纸、信封、冻结那天的 Design System 样式和上墨脚本），`design.json` 记名字、版本、哪天冻结、校验和 |

审看在 Pomelo Explore 的「R5：Atlas 年度小报」一页（`canvases/pomelo-explore/atlas/`，用 `sample.mjs` 的数据把它摆出来）。同步清单 `sync.json` 里每一份快照两行，同步到 Pomelo 的 `src/vendor/pomelo/atlas/`，每一份都留在那边。

```bash
npm run build:atlas
```

```bash
node tooling/atlas/build.mjs --freeze tabloid
```

```bash
npm run check:atlas
```

第一条打包到 `dist/pomelo/atlas/`（先 `npm run build:ds`：快照里要带 Design System 的样式）；第二条把现在的源冻结成 `releases/` 里的一份（同一个版本冻结过、源又改了会拒绝；同一条线里旧的小修版删掉）；第三条核对每份快照没被改过、一条线只有一份。冻结以后改 `sync.json`：小修把那两行换成新的，新定稿加两行。

## 快照怎么用

`design.js` 导出 `design`：

| 成员 | 内容 |
| --- | --- |
| `id`、`name`、`version` | `tabloid`、`Tabloid`、`1.0.3` |
| `frame()` | 放它的那个 frame 的文档（`srcdoc`）：样式和上墨脚本都在里面，`body` 是空的 |
| `mount(host, 呈现结果, opts)` | 挂到那个文档的 `body` 里。`opts`：`desk`（先摆桌上的信封，默认是；`false` 直接是翻开的小报）、`backdrop`（自己铺一层桌面）、`palette`、`theme`（`light` / `dark`）、`reduce`（减弱动态效果）、`hooks`。回 `{ root, set(外观), destroy() }` |
| `envelope(年)` | 桌上那个信封的 HTML（首页新年第一周摆的） |
| `cover({ year, until })` | Atlas 页上的封面（1.0.2 起有）：一段 168 × 218 的 HTML，直接摆在页上（不进 frame，只用行内样式和 Design System 的变量）。`until` 是没过完的年写到哪天，盖「截至某日」；名字和版本号快照自己填。歪不歪、叠不叠、点了做什么由摆它的地方管 |
| `css` | 设计自己的样式 |

`hooks`：`openRecord(记录的键)`（纸条上的「在模块里打开」，不给就不出这个按钮）、`onClose()`（收进抽屉以后）、`onEscape()`（没有纸条开着时按了 Esc）。

放在 frame 里是为了隔开：外面的样式进不来，里面的出不去，和审看画布是同一个环境。

## 数据（一份「呈现结果」）

Pomelo `src-tauri/src/youzi/atlas.rs` 存的，`atlas_get` 给出来的样子。数字、日期、图都是程序照快照画的；模型只写每一幕那一两句话、挑要引用的记录、给聊天的话题分类。

```
{
  year: "2026", until: "2026-11-10" | null,      // until：今年没过完，写到哪天
  createdAt, design: "tabloid@1.0.0", modelName,
  letter,                                        // 柚子的整封信（终章点「读整封信」）
  snapshot: {
    numbers: [{ label, unit, n, last }],         // 这一年的数字；last 是去年同期（没有去年是 null）
    heat: [{ day, notes, all }],                 // 有记录的每一天：几条笔记、一共几条
    records: [{ key, kind, day, text, tags? }],  // 能引用、能点开的记录，key 像 note:12；tags 只有见字如面的文章有（1.1.1）
    echo: [{ day: "03-14", this: [键], last: [键] }],   // 两年同一天都有笔记
    habits: [{ title, days, longest, longestFrom, weeks: [每周打了几天] }],
    money: { spent: [{ currency, kind, amount }], income, assets: { fromDay, from, toDay, to } } | null,   // 金额是分
    jobStages: [{ label, n, unit, got }],        // 求职的石头：有进展 → 走到最多的两步 → Offer
    offered: [幕],                               // 这一年有内容的幕（自建模块的键跟在后面）
    games: [{ key, title, platform, kind, rating, runs }],   // 1.1.0：这一年通关的游戏（第一次或又一个周目），runs 是一共几周目
    gamesLast,                                   // 1.1.0：去年通关几个（老的数据没有）
    made: [{ key, name, template, mark, n, last, months, fields, items, courses, quotes, plan, … }],  // 1.1.0：自建模块，见下面
    writing: { n, chars, last: { n, chars } | null, untagged, months: [12 个], tags: [{ name, n, kids: [{ name, n }] }] } | null   // 1.1.1：见字如面这一年，见下面
  },
  scenes: [{ key, lines: [话], refs: [键], topics?, plan?, quotes? }] | null,   // 模型写的；null 是那一步没写成（照 offered 画，没有话）
                                                 // 自建模块那一幕的 plan 是柚子给的排法（数字由 Pomelo 填好）
                                                 // 重要的时刻的 quotes：[{ key, text }] 每篇抄的一句（1.1.1）
                                                 // 序章的 refs：柚子挑的、这一年触动你的几条（1.0.2 起画成粉星）
  error
}
```

记录的种类（`kind`）：`note` 笔记、`goal` 做完的目标、`trip` 出行、`offer` 拿到的 Offer、`day` 来日方长的日子、`book`、`film`、`course` 画完的课、`talk` 和柚子的对话；1.1.0 加了 `game` 玩物有志的游戏、`made` 自建模块的条目（键像 `list/3:41`）和课程（`progress/2:21`）；1.1.1 加了 `article` 见字如面的文章（`text` 是标题）。

序章的 `refs`（1.0.2 起用）：模型挑 3～5 条这一年对你最重要、最触动的记录（哪一类都行，要有今年的日子；亲密关系、家人、离别重逢、做成的大事这类）。设计把那一天画成粉星，和最亮的五天（金星）按日子连成星座；点粉星弹出挑的那一条。以前的数据序章没挑记录，就只有金星。

十四幕的键（两边同一份）：`prologue` 序章、`days` 留下的日子、`writing` 写下的字和 `writing-moments` 重要的时刻（1.1.1）、`works` 书影相遇、`games` 玩物有志（1.1.0）、`moments` 几个具体时刻、`echo` 去年的回声、`drawing` 创作、`jobs` 求职这一年、`habits` 身体和习惯、`talks` 和柚子聊的事、`money` 钱、`finale` 终章；自建模块一个模块一幕，键是模块的键（`list/3`、`progress/2`），排在创作后面。`scenes` 里没有的幕整页不出现；幕里缺的那一块（没挑引用、没有去年、老的数据没有 `weeks`）就不画那一块或者用一个凑合的样子，不报错。

以后给数据加东西只能加，不能改已有的意思：旧的快照还要读新存的数据，新的快照也要读旧的数据。

## 写下的字（1.1.1）

见字如面这一年的两幕，紧跟留下的日子（`writing.mjs`）。

- **写下的字**（`writing`）全是 Pomelo 算的数，没有模型的话：`writing` 里 `n` 这一年新写的篇数、`chars` 字数（不算空白）、`last` 去年同期（没有去年是 null）、`untagged` 没打标签的、`months` 每个月几篇、`tags` 主标签（「旅行/东京」的「旅行」）和它下面的子标签各几篇，按篇数排。页上：几篇、多少字、和去年比；标签长成一棵树（主标签是左右伸出去的枝，最多 6 根，名字和篇数写在枝头；子标签是枝上的小枝，每根最多 3 个，枝头垂的柚子大小是篇数、不写数字，放不下的不画）；树干下面挂一块木牌写没打标签的几篇（0 篇不挂）；十二支铅笔，写得越多削得越短，最多的那支是柚黄、头上写几篇。
- **重要的时刻**（`writing-moments`）：柚子挑 3～5 篇（`refs`），每篇抄一句原文（`quotes`，Pomelo 核对过是那篇里的话，不是就换成那篇的第一句），附言写在 `lines`。第一篇抄的那句写进两行稿纸（36 格），其余按日子排成书签（左边一截写日子，右上写那篇的标签的最后一层）；最下面是附言（最多 60 个字）。一篇都没挑就只有附言，附言也没有这一页就不出现。

## 自建模块的一幕（1.1.0）

五花八门、循序渐进建的模块，这一年有数据的一个模块一页。程序不定死这一页的样子：这里给十个零件、三种排法，Pomelo 让柚子照 SKILL 给每个模块排（不想放的回 skip），Rust 核对（零件能不能放那个位置、字段在不在、是不是那种字段、引用的话在不在），不对告诉柚子再要两次，还不行用默认的排法；数字一律 Pomelo 填（`youzi/made.rs`）。

`made[]` 每个模块：`key`、`name`、`template`（`list` / `progress`）、`mark`（右上角的贴纸，自建模块能戴的那 24 张之一，`parts.mjs` 的 `MADE_MARKS`）、`n` 这一年几条（几节）、`last` 去年、`months` 十二个月、`courseWord` `lessonWord`（循序渐进的两级叫法）、`fields`、`items`、`courses`、`quotes`，和 `plan`（默认的排法，没有柚子的排法时画它）。

`plan`：`{ layout: hero | pair | list, parts: [{ slot, part, data }] }`。位置：hero 是 H（宽的大块）、S（一条）、Q（一张纸条）；pair 是 A、B 两半和 S、Q；list 是 H（高的一大块）、A、B。每个零件的 `data`：

| 零件 | 能放 | data |
| --- | --- | --- |
| `big` 大数字 | H A B | `{ label, n, unit, last? }` |
| `compare` 和去年比 | H A B | `{ label, n, last, unit }` |
| `stars` 一排星 | H A B | `{ label, items: [{ key, title, rating }] }` |
| `dist` 分布条 | H A B | `{ label, rows: [{ name, n }] }` |
| `chips` 多选的词 | H A B | `{ label, rows: [{ name, n }] }`（字在圆的正中，圆跟着字撑开，放不下的从用得少的起不放） |
| `sum` 合计（小票） | H A B | `{ label, rows: [[名字, 数]], total, unit }` |
| `courses` 学的几门 | H A | `{ label, unit, items: [{ key, name, done, total, year, finished? }] }`（finished 是 YYYY-MM） |
| `months` 十二个月 | S | `{ label, values: [12 个], unit }` |
| `cards` 条目卡 | Q H | `{ items: [{ key, title, sub: [字], rating? }] }` |
| `quote` 引用 | Q | `{ key, text, from }` |

不认识的排法、零件、位置都跳过（以后加零件是新版本，旧的照旧画）。

## 聊天页的泡泡

`talks` 这一幕多一个 `topics: [{ name, kind, n, refs }]`（最多 6 个）。

- **模型不挑泡泡。** 它只把这一年的对话按话题归组，给每组起名字、从固定的 12 个类别里挑一个（都不合适就是 `other`）。类别不认识的当 `other`；次数 `n` 是程序数这一组有几个对话，不听模型的。
- **画什么由设计定**（`bubbles.mjs`）：类别有专属泡泡、这一页还没用过，就用它；`other`、重复的类别用通用的，轮着来，一页里不重样。
- 所以哪一年聊什么都画得出来：没聊过做饭，冒热气的泡泡就不出现；聊了没画过的话题，用通用的。以后给某个类别补专属泡泡，是设计的新版本，数据不用动。

| 类别（`kind`） | 话题 | Tabloid 的专属泡泡 |
| --- | --- | --- |
| `cook` | 做饭、吃喝 | 冒热气的圆泡 |
| `work` | 求职、面试、工作 | 炸开的，旁边三道紧张的线 |
| `code` | 代码、技术 | 小窗口，字后面一根闪着的光标 |
| `travel` | 旅行、出门 | 盖了邮戳的邮票 |
| `pet` | 宠物 | 长着耳朵和胡子 |
| `sleep` | 睡眠、熬夜 | 夜色的思考云，月亮和小星星 |
| `love` | 感情、亲密关系 | 一颗心，旁边飘着一颗小的 |
| `money` | 钱、理财、消费 | 价签，打了孔穿着线 |
| `study` | 学习、读书、考试 | 线圈本的一页 |
| `health` | 身体、运动、健康 | 圆泡，一道心跳，角上一个十字 |
| `mood` | 心情、烦恼 | 下着雨的云 |
| `family` | 家人、朋友 | 一间小房子 |

通用的 6 个：圆泡、方泡、水滴、票根、云朵、悄悄话（虚线）。一页最多 6 个话题，通用的够排满一页不重样。

## Tabloid 1.0.3

1.0.x 做的都照它画（替掉了 1.0.0～1.0.2）。

- **翻页**：桌上的信封拆开，一本小报跟着节拍自己翻（一拍 0.8 秒，翻一页是一拍），碰一下就停；下面一排是上一页、每个跨页一个点、下一页、自动翻、目录、收进抽屉。点星星、纸条、卡片弹出原记录（一张纸条从纸卷里卷开）。今年不做音乐（站主 2026-11-10）。减弱动态效果时页直接换，一闪而过的东西不出现。
- **颜色**：印出来的纸（每一页、弹出的纸条、封面）一律按浅色画，纸落在桌上的影子跟桌面的明暗走。星图的夜色 `#2A3158`、`#3A4474` 和复写纸的蓝 `#5B6FA8`、`#E6ECF8` 是这份设计自己的颜色，写在 `draw.mjs`。
- **各幕的动静**：序章的流星和一笔连出来的星座；留下的日子一行行绣出来；求职的小石子跳过水面；钱的小票从出纸口吐出来、合计像里程表滚出来；回声的条和数字；聊天页的泡泡从尾巴尖弹出、柚子先「正在输入」再回一句；终章一段段浮出来、能读整封信。节拍表在 Pomelo Explore 的 `Atlas-Desk` 板上。
- **封面**（`cover.mjs`）：Atlas 页上一年一张，是小报头版缩小的样子：报头「柚子的年度小报」和两道线、年份、柚黄的一笔、三颗纸星星、柚子（哇）、顶上一条薄荷胶带；左下一个小框印着这一版的名字和版本号；全年写「这一年 / 都在这本里了」，没过完盖红章「截至某日」。
- **序章的粉星**：柚子挑的触动你的几天画成粉星（樱粉 `--color-cat-pink`，描边和金星一样），和金星按日子连成星座；既是最亮又是挑中的那天，粉星外面一圈金色。挑的那天没有别的记录（比如来日方长的日子）也照日子摆上去。图例有一项「触动你的几天」。点粉星弹出挑的那一条，点金星是那一天的几条。
- **落签**：下面一排按钮的纸签，鼠标移上去时量出按钮里画的线在正中那一竖上最低到哪，线从那下面 3 像素开始；按钮自己有底色时从底色下面算。
- **整封信按 Markdown 排**：终章「读整封信」弹出的信，`## 小标题`、`**加粗**`、列表、`>` 引用、分隔线都排出来。先整段转义再认记号，链接只留字。
- **留下的日子**：格子从 106 开始，一行 19 像素，最下面那句离纸边 50 像素左右。
- **印在页上的笔记**（留下的日子、去年的回声、点开的纸条的标题、星图上那一天的几行）不带开头的标签（`#日记`）和 Markdown 的记号（`**`、`==`、行首的 `#` `>` `-`），只留字；点开的纸条里还是原文。
- **小处**：聊天页「感情」的泡泡，字在心的正中；钱那一页「花得最多的是…，平均每天 ¥…」，平均每天不到一块时不写后半句。
